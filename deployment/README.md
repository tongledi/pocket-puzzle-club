# GitHub Pages project preview

The repository contains static files and requires no build step. After publication is authorized, configure Pages to deploy from the `main` branch at `/ (root)`. The root `index.html` redirects to `./dist/`, preserving query and hash routes when JavaScript is enabled. `.nojekyll` disables Jekyll processing. Upload actual files and folders, not a ZIP.

No GitHub Actions deployment workflow, personal token, secret, custom domain or CNAME is configured. No open-source license has been granted. A source backup archive is for recovery only.

GitHub Pages is intended here only for a project preview with no ads or commerce. It is not promised as the eventual commercial host. See [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) and [publishing sources](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Browser gameplay and mobile visual QA remain unverified. Verify the actual preview URL after publication; passing Node tests alone is not visual QA. Saves remain local to the browser and hosting origin.
